# AirCanvas Studio 🎨

A webcam-controlled drawing application that lets you draw in the air using hand gestures.

## Features

- Mouse Mode and Air Mode
- Hand tracking with MediaPipe
- Pinch-to-draw interaction
- Pen and eraser tools
- Brush color and size controls
- Undo and clear canvas
- Export drawings as PNG
- Fullscreen canvas

## Technologies

- HTML
- CSS
- JavaScript
- MediaPipe Hands

## Run locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern browser.
4. Allow camera access when prompted.
5. Select Air Mode and show your hand to the webcam.

If camera access is blocked when opening the file directly, run it through a local development server, such as the Live Server extension in VS Code.

An internet connection is needed to load MediaPipe from its CDN.

## Notes

A webcam and adequate lighting are required for hand tracking.
A projector is not required.

Project implementation developed independently for learning
and portfolio purposes.
